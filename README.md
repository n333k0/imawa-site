# IMAWA — Website

Static marketing site for IMAWA. Plain HTML/CSS/JS, no build step.

## Run locally
```bash
npx serve .        # or: python3 -m http.server 8090
```

## Pages
`index` · `work` · `services` · `about` · `contact`

## Notes
- Palette sampled from the official brand lockups: `#EBEBEB` base, `#BAA47B` cream-gold accent.
- Logos extracted from the vector brand PDFs with transparency preserved.
- All imagery is placeholder. See `prompt.md` for the brief and open items.
